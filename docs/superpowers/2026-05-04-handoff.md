## 7.1 Git Commit 단위 가이드

ZIP 다운로드본이라 현재 `.git` 연결이 없을 수 있다. Git을 연결한 뒤에는 아래 단위로 작게 커밋한다.

- `cost`: 거래세/수수료 결정 spec, `config.py`, 비용 회귀 테스트.
- `phase3-stops-tests`: 손절/트레일링 실패 테스트와 fixture 보강.
- `phase3-stops-engine`: 백테스트 엔진 stop 구현.
- `phase3-stops-cli-docs`: CLI 플래그와 spec 문서.
- `phase1-quality-schema`: DART config, quality tables, repository 테스트.
- `phase1-quality-provider`: RateLimiter, DART provider, quality sync 테스트.
- `phase1-quality-script`: 수동 sync 스크립트와 help/argparse 테스트.
- `phase2-quality-spec-tests`: quality score spec과 실패 테스트.
- `phase2-quality-engine`: factor engine quality_score 구현과 logging.

원칙: 서로 다른 plan의 코드 변경을 한 커밋에 섞지 않는다. 문서만 수정한 작업도 구현 커밋과 섞지 않고 별도 커밋으로 남기는 편이 추적하기 쉽다.
